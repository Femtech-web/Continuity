# Keep lifecycle safety primary and make agent markets the launch wedge

Continuity is a lifecycle-safety layer for stock-quoted markets, not a general-purpose token launchpad. The fixed `CONT/SPCXx` launch is a first-party Protected Agent Market for the Continuity Sentinel agent; future operators may create their own agent markets only through verified stock quote assets and non-optional Sentinel safeguards. This preserves the differentiated evidence-to-Meteora-to-monitoring loop even though ClawPump already supports simpler agent-token launches against approved Pump.fun custom pairs.
